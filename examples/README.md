# Worked examples

These are **real briefs** that were actually dispatched through the flywheel loop and landed —
not illustrations. Read them for the format in practice; copy from them when you write your own.

- [gmail-draft.brief.md](gmail-draft.brief.md) — a complete fresh-run brief. The commentary
  block at the top explains how it satisfies each rule; the brief itself (from `# TASK:` down)
  is reproduced verbatim and is copy-pasteable.
- [gmail-draft.delta.md](gmail-draft.delta.md) — the correction form: a delta brief that states
  only the defect and the fix, dispatched with `--session <emitted id>` to resume the same
  worker rather than restart it.
